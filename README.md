# Rain Detection Clothes Shield

## About the Project

Rain Detection Clothes Shield is an embedded systems project designed to protect clothes from sudden rain. A rain sensor detects rain and the system uses a servo motor to automatically move the clothes shield.

This project was developed as a team project.

## How It Works

1. The rain sensor continuously checks for rain.
2. The sensor value is read by the Vega Processor.
3. When rain is detected, the servo motor moves to close the shield.
4. When there is no rain, the servo motor moves to open the shield.
5. The sensor readings can be monitored through the Serial Monitor.

## Hardware Used

- Vega Processor
- Rain Sensor
- Servo Motor
- Connecting Wires
- Power Supply

## Software Used

- Arduino IDE
- Arduino-compatible C/C++
- Servo Library
